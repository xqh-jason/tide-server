# 前端对接说明：登录图形验证码（W5-5）

> 面向前端 AI agent 的对接文档。后端已完成并验证，本文描述需要改动的全部前端契约点。
> 后端仓库：salvo-vben-admin（本项目为 vue-vben-admin 前端服务）。

## 1. 变更总览

| # | 变更 | 影响 |
|---|---|---|
| 1 | 新增验证码生成接口 | 登录页新增验证码图片 + 点击刷新 |
| 2 | 登录接口请求体新增 2 个**必填**字段 | 现有登录调用**不传必报错**，必须同步改造 |
| 3 | 登录失败文案新增两种验证码提示 | 需联动刷新验证码图 |

其余登录契约（响应体、token 用法、401 处理）不变。

## 2. 接口一：生成验证码（新）

```
POST /api/v1/captcha/generate
```

- 无需登录态，无请求体（可传 `{}`，不传亦可）；
- 响应（统一 `{ code, data, message }` 信封，`code=1` 成功）：

```json
{
  "code": 1,
  "data": {
    "captchaId": "0c62a51b24804f7591bd75c5c99e53fa",
    "image": "iVBORw0KGgoAAAANSUhEUg..."
  },
  "message": "ok"
}
```

- `captchaId`：本次验证码的唯一 id，登录时原样回传；
- `image`：**裸 base64** PNG 字符串（**不带** `data:` 前缀），展示时需自行拼接：

```html
<img :src="`data:image/png;base64,${image}`" alt="验证码" @click="refreshCaptcha" />
```

- 有效期 **3 分钟**，过期后登录会报「验证码已过期，请刷新」。

## 3. 接口二：登录（契约变更，破坏性）

```
POST /api/v1/auth/login
```

请求体（`captchaId` / `captchaValue` 为**必填**，缺失直接参数错误）：

```json
{
  "username": "admin",
  "password": "admin123",
  "captchaId": "0c62a51b24804f7591bd75c5c99e53fa",
  "captchaValue": "3456"
}
```

- `captchaValue`：用户在图上看到的 4 位**数字**；首尾空格与大小写后端已做容错；
- 响应体不变：`{ "code": 1, "data": { "token": "..." } }`，token 后续用法不变。

## 4. 错误提示与联动（必须实现）

后端验证码相关错误统一 HTTP 200 + `code=0`，`message` 有两种：

| message | 含义 | 前端动作 |
|---|---|---|
| `验证码错误` | 用户输入不匹配（该验证码已被消费） | **刷新验证码图** + 清空输入框 + 提示 |
| `验证码已过期，请刷新` | 超过 3 分钟或 id 不存在 | **刷新验证码图** + 清空输入框 + 提示 |

注意：验证码**一次性消费**——同一 `captchaId` 校验一次（无论成败）即失效，
登录失败重试前必须先刷新图片拿新的 `captchaId`。

其余登录失败仍返回 `用户名或密码错误`（不刷新验证码逻辑可保持不变，但建议统一刷新，
因验证码已被消费，必须刷新后才能再次尝试登录）。

## 5. 建议实现（vben 登录页）

1. 登录组件 `onMounted` 与「点击图片」时调用生成接口，保存 `captchaId` 与 `image`；
2. 登录提交把 `captchaId`、`captchaValue` 一并放入 body；
3. 收到 §4 两种 message（或任何登录失败）时：调生成接口刷新图、清空 `captchaValue`；
4. 表单校验：`captchaValue` 必填、4 位数字。

伪代码：

```ts
async function refreshCaptcha() {
  const res = await request.post('/captcha/generate');
  captchaId.value = res.data.captchaId;
  captchaImg.value = `data:image/png;base64,${res.data.image}`;
}

async function handleLogin() {
  try {
    const res = await request.post('/auth/login', {
      username: username.value,
      password: password.value,
      captchaId: captchaId.value,
      captchaValue: captchaValue.value,
    });
    // 正常存 token、跳转
  } catch (e) {
    await refreshCaptcha();      // 验证码已被消费，必须刷新
    captchaValue.value = '';
  }
}
```
