# W4 代码生成器实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 从「域定义 JSON」自动生成 entity + 每域四件套（api/service/repo/dto）+ mod.rs，并用它产出数据字典（dict）域作为验证。

**架构：** 独立 binary crate `codegen/`；serde 反序列化域定义 → 校验 → Rust 模板字符串按文件生成；输出写入 `src/entity/` 与 `src/modules/<domain>/`。表结构迁移由 migrations 人工维护。

**技术栈：** Rust（无外部模板引擎）、serde/serde_json、SeaORM 既有模式（`crate::utils::paginate` / `PageData` / `<Domain>Filter`）。

**设计规格：** `docs/superpowers/specs/2026-09-01-w4-codegen-design.md`

---

## 文件结构

**codegen crate（新建）：**
- `codegen/Cargo.toml` — binary crate，依赖 serde/serde_json/anyhow
- `codegen/src/main.rs` — 入口：解析 CLI 参数（`generate <def.json>`）
- `codegen/src/def.rs` — `DomainDef` 定义结构 + 校验
- `codegen/src/typing.rs` — `rust_type` → SeaORM `ColumnType` 映射
- `codegen/src/templates.rs` — 六个文件的模板函数（entity/repo/service/dto/api/mod）
- `codegen/src/generate.rs` — 生成编排（写文件、打印清单）
- `codegen/defs/dict.json` — 数据字典域定义（验证目标）

**现有项目修改：**

- `src/modules/mod.rs` — 生成后挂载 `pub mod dict;`
- `src/infra/router.rs` — 生成后挂载 `/dict` 路由（AuthRequired）

**生成产物（由生成器输出，非手写）：**
- `src/entity/sys_dict.rs`
- `src/modules/dict/{api,service,repo,dto}.rs` + `mod.rs`

```rust
// def.rs
use serde::Deserialize;

#[derive(Debug, Clone, Deserialize)]
pub struct DomainDef {
    pub domain: String,
    pub table: String,
    pub comment: String,
    pub fields: Vec<FieldDef>,
    #[serde(default)]
    pub unique_fields: Vec<String>,
    #[serde(default)]
    pub filters: Vec<FilterDef>,
}

#[derive(Debug, Clone, Deserialize)]
pub struct FieldDef {
    pub name: String,
    pub rust_type: String,
    pub sql_type: String,
    #[serde(default)]
    pub primary: bool,
    #[serde(default)]
    pub auto_increment: bool,
    #[serde(default)]
    pub optional: bool,
    #[serde(default)]
    pub readonly: bool,
    #[serde(default)]
    pub soft_delete: bool,
    #[serde(default)]
    pub unique: bool,
    #[serde(default)]
    pub default: Option<serde_json::Value>,
    #[serde(default)]
    pub comment: Option<String>,
}

#[derive(Debug, Clone, Deserialize)]
pub struct FilterDef {
    pub field: String,
    pub kind: String,
}

impl DomainDef {
    pub fn from_json(json: &str) -> anyhow::Result<Self> {
        let def: DomainDef = serde_json::from_str(json)?;
        def.validate()?;
        Ok(def)
    }

    pub fn validate(&self) -> anyhow::Result<()> {
        anyhow::ensure!(!self.domain.is_empty(), "domain 不能为空");
        anyhow::ensure!(!self.table.is_empty(), "table 不能为空");
        anyhow::ensure!(!self.fields.is_empty(), "fields 不能为空");
        anyhow::ensure!(self.fields.iter().any(|f| f.primary), "必须存在 primary 字段");
        for name in &self.unique_fields {
            anyhow::ensure!(self.fields.iter().any(|f| &f.name == name), "unique_fields 引用不存在的字段: {name}");
        }
        for f in &self.filters {
            anyhow::ensure!(self.fields.iter().any(|fd| &fd.name == &f.field), "filters 引用不存在的字段: {}", f.field);
            anyhow::ensure!(f.kind == "exact" || f.kind == "keyword", "filter kind 只能是 exact/keyword: {}", f.kind);
        }
        Ok(())
    }
}

// main.rs
fn main() -> anyhow::Result<()> {
    let args: Vec<String> = std::env::args().collect();
    if args.len() < 3 || args[1] != "generate" {
        anyhow::bail!("用法: codegen generate <def.json>");
    }
    let json = std::fs::read_to_string(&args[2])?;
    let def = codegen::def::DomainDef::from_json(&json)?;
    println!("定义校验通过: {} ({})", def.domain, def.table);
    Ok(())
}
```

注意：`codegen/src/main.rs` 里引用库模块，需要把 def 做成同 crate 模块（`mod def;`），
或建 `lib.rs`。第一版直接 `mod def; mod typing; mod templates; mod generate;` 放 main.rs 同级。

use crate::def::{DomainDef, FieldDef};

pub fn render_entity(def: &DomainDef) -> String {
    let fields = def.fields.iter().map(render_entity_field).collect::<Vec<_>>().join("\n");

use sea_orm::entity::prelude::*;

#[derive(Clone, Debug, PartialEq, DeriveEntityModel, Eq)]
#[sea_orm(table_name = "{table}")]

{fields}
}}

pub enum Relation {{}}

impl ActiveModelBehavior for ActiveModel {{}}

            line = format!("    #[sea_orm(primary_key, auto_increment = true)]\n    pub {}: {},", f.name, f.rust_type);

    }

```rust
impl DomainDef {
    /// 表名转实体标识：sys_dict → sys_dict
    pub fn entity_ident(&self) -> String { self.table.clone() }
    /// 域名单词驼峰：dict → Dict
    pub fn camel(&self) -> String {
        self.domain.split('_').map(|w| {
            let mut c = w.chars();
            match c.next() { Some(f) => f.to_uppercase().collect::<String>() + c.as_str(), None => String::new() }
        }).collect()
    }
    /// 唯一字段名列表（字段级 unique 或 unique_fields 声明）
    pub fn unique_field_names(&self) -> Vec<String> {
        let mut names: Vec<String> = self.fields.iter().filter(|f| f.unique).map(|f| f.name.clone()).collect();
        names.extend(self.unique_fields.iter().cloned());
        names.sort();
        names.dedup();
        names
    }
}
```

pub fn write_all(def: &DomainDef, root: &std::path::Path) -> anyhow::Result<()> {
