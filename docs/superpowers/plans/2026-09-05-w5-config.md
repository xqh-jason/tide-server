**目标：** 键值参数配置（sys_config，通用 CRUD + key 唯一查重）与网站设置
（sys_site_config 单行，公开读取 + 登录更新）两套能力。

**架构：** 一个域 `modules/config` 内分「参数（Param）」与「网站设置（Site）」两组；
sys_config 走 codegen，sys_site_config 手写 entity；网站设置 get 公开、update 登录态。

**技术栈：** sea-orm 迁移 / codegen 生成器 / fill_user_names 名称管道（已有）。

```rust
pub fn routes() -> Router {          // 参数 CRUD，router.rs 包 AuthRequired+OperationLog
    Router::new().oapi_tags(["参数配置"])
        .push(Router::with_path("list").post(api::list_configs))
        .push(Router::with_path("create").post(api::create_config))
        .push(Router::with_path("update").post(api::update_config))
        .push(Router::with_path("get").post(api::get_config))
        .push(Router::with_path("delete").post(api::delete_config))
}
pub fn site_routes() -> Router {     // 网站设置：get 公开 / update 自挂 AuthRequired
    Router::new().oapi_tags(["网站设置"])
        .push(Router::with_path("get").get(api::get_site_config))
        .push(Router::with_path("update")
            .hoop(AuthRequired).hoop(OperationLog).post(api::update_site_config))
}
```
