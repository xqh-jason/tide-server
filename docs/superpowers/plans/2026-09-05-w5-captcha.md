# W5-5 图形验证码 实现计划

> **面向 AI 代理的工作者：** 本计划遵循仓库协作约定——**Rust 业务实现由用户手写**，
> AI 提供签名骨架与失败测试，实现后由 AI review。步骤用 [AI] / [用户] 标注执行者，
> 复选框跟踪进度。
> 规格依据：`docs/superpowers/specs/2026-09-05-w5-captcha-design.md`

**目标：** 登录接口接入图形验证码：公开 generate 端点出 4 位数字 PNG（裸 base64），
登录请求带 `captcha_id + captcha_value` 强校验，cache 一次性消费、TTL 3 分钟。

**架构：** 新建 `modules/captcha` 域（api/service/dto，无 repo——cache 即存储）；
`auth::service::login` 最先调用 `captcha::service::verify_captcha`，先验码后查库。
存储复用 `AppState.cache`（`utils::cache::Cache`），key 前缀 `captcha:`。

**技术栈：** salvo 0.95、`captcha = "1"`（新依赖）、uuid v4（已有）、dashmap MemoryCache（已有）。

`generate_captcha` 实现提示（规格 §4，答案生成不引 rand）：

```rust
// 1. 答案：uuid v4 前 4 字节各 % 10 → 4 位数字
let bytes = uuid::Uuid::new_v4().as_bytes();
let answer: String = bytes[..CHARS].iter().map(|b| char::from(b'0' + b % 10)).collect();
// 2. 渲染：逐位喂字符（候选池只放当前位），再加噪点/波浪
let mut c = Captcha::new();
for ch in answer.chars() {
    c.set_chars(&[ch]);
    c.add_chars(1);
}
c.apply_filter(Noise::new(0.3))
    .apply_filter(Wave::new(2.0, 10.0))
    .view(180, 44);
// 3. as_base64() 返回 Option<String>，None → AppError::Internal("验证码图像生成失败")
// 4. captcha_id = uuid v4 simple hex；cache.set(&format!("{KEY_PREFIX}{captcha_id}"), answer, Duration::from_secs(TTL_SECS))
```

`mod.rs` 与 `api.rs`（公开端点，无 AuthRequired）：

```rust
// mod.rs
pub mod api;
pub mod dto;
pub mod service;

/// 验证码端点：`POST /api/v1/captcha/generate`（公开路由，不挂 AuthRequired）。
pub fn routes() -> Router {
    Router::new()
        .oapi_tags(["验证码"])
        .push(Router::with_path("generate").post(api::generate_captcha))
}

// api.rs
#[endpoint]
pub async fn generate_captcha(depot: &mut Depot) -> ApiResult<CaptchaGenerateResp> {
    let state = AppState::from_depot(depot)?;
    Ok(ApiResponse::ok(captcha_service::generate_captcha(state.cache.as_ref())?))
}
```

### 2.2 [AI] 失败测试（service.rs 内 `#[cfg(test)]`，纯单元、不连 MySQL）

```rust
#[cfg(test)]
mod tests {
    use super::*;
    use crate::utils::cache::MemoryCache;

    /// 从 cache 直读答案（生成接口不回传答案，测试走存储层拿）
    fn cached_answer(cache: &MemoryCache, captcha_id: &str) -> String {
        cache.get(&format!("{KEY_PREFIX}{captcha_id}")).unwrap()
    }

    #[test]
    fn generate_captcha_returns_png_base64_and_stores_answer() {
        let cache = MemoryCache::new();
        let resp = generate_captcha(&cache).unwrap();

        assert!(!resp.captcha_id.is_empty());
        assert!(resp.image.len() > 100, "base64 应为完整 PNG");
        assert!(resp.image.starts_with("iVBOR"), "PNG 的 base64 固定前缀");
        assert!(cache.exists(&format!("{KEY_PREFIX}{}", resp.captcha_id)), "答案应已入 cache");
        assert_eq!(cached_answer(&cache, &resp.captcha_id).chars().count(), CHARS);
    }

    #[test]
    fn verify_correct_answer_passes_and_single_use() {
        let cache = MemoryCache::new();
        let resp = generate_captcha(&cache).unwrap();
        let answer = cached_answer(&cache, &resp.captcha_id);

        verify_captcha(&cache, &resp.captcha_id, &answer).unwrap();
        assert!(
            cache.get(&format!("{KEY_PREFIX}{}", resp.captcha_id)).is_none(),
            "一次性消费：验证通过后立即失效"
        );
        let second = verify_captcha(&cache, &resp.captcha_id, &answer);
        assert!(matches!(second, Err(AppError::Biz(ref m)) if m.contains("已过期")));
    }

    #[test]
    fn verify_wrong_answer_fails_and_consumes() {
        let cache = MemoryCache::new();
        let resp = generate_captcha(&cache).unwrap();
        let key = format!("{KEY_PREFIX}{}", resp.captcha_id);
        let answer = cached_answer(&cache, &resp.captcha_id);
        let wrong = if answer == "0000" { "1111" } else { "0000" }.to_string();

        let first = verify_captcha(&cache, &resp.captcha_id, &wrong);
        assert!(matches!(first, Err(AppError::Biz(ref m)) if m.contains("验证码错误")));
        assert!(cache.get(&key).is_none(), "失败同样消费，防反复试同一码");
    }

    #[test]
    fn verify_unknown_id_reports_expired() {
        let cache = MemoryCache::new();
        let err = verify_captcha(&cache, "ghost-id", "1234");
        assert!(matches!(err, Err(AppError::Biz(ref m)) if m.contains("已过期")));
    }

    #[test]
    fn verify_is_case_insensitive_and_trims() {
        let cache = MemoryCache::new();
        let resp = generate_captcha(&cache).unwrap();
        let answer = cached_answer(&cache, &resp.captcha_id);
        // 数字集下大小写无感，此用例锁定「trim + 小写」行为为未来字母集留余地
        let padded = format!("  {}  ", answer.to_uppercase());
        verify_captcha(&cache, &resp.captcha_id, &padded).unwrap();
    }
}
```

        captcha_id: resp.captcha_id,

### 3.2 [用户] 实现（规格 §4）

- `dto.rs`：`LoginReq` 加 `pub captcha_id: String`、`pub captcha_value: String`（必填，不加 serde 默认）；

```rust
// 先验码后查库：注定失败的登录不浪费 DB 查询

```

- `api.rs`：login handler 调用处加 `&state.cache`（`state.cache` 是 `Arc<dyn Cache>`，传 `&state.cache` 自动解引用为 `&dyn Cache`；若编译报错则写 `state.cache.as_ref()`）；
- 登录日志：验证码失败发生在 `record_login` 之前，msg 记两档——在 auth::service 里对
  verify 的 Err 下探（`match` 拆 Biz message）调 `record_login(db, &req, 0, 0, "验证码错误/已过期", &meta)`
  后再返回错误；
